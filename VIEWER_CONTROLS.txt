====================================
  ODE Tutorial - Viewer Controls
  カメラ操作ガイド
====================================

このファイルはすべてのチュートリアルに共通のビューワー操作方法を説明します。

====================================
  マウス操作
====================================

左ドラッグ (Left Drag):
  カメラの視点角度を変更
  - 左右: ヨー角（水平回転）
  - 上下: ピッチ角（垂直回転）

右ドラッグ (Right Drag):
  ズームイン/アウト
  - 上: ズームイン（近づく）
  - 下: ズームアウト（遠ざかる）

マウスホイール (Mouse Wheel):
  ズームイン/アウト
  - 上スクロール: ズームイン
  - 下スクロール: ズームアウト

====================================
  キーボード操作（トラックパッド対応）
====================================

ズーム (Zoom):
  + または =    : ズームイン（近づく）
  - または _    : ズームアウト（遠ざかる）
  Z            : ズームイン（代替キー）
  X            : ズームアウト（代替キー）

カメラパン - 矢印キー (Camera Pan - Arrow Keys):
  ↑ (Up)       : 前方へ移動
  ↓ (Down)     : 後方へ移動
  ← (Left)     : 左へ移動
  → (Right)    : 右へ移動

カメラパン - IJKL (Camera Pan - IJKL):
  I            : 前方へ移動
  K            : 後方へ移動
  J            : 左へ移動
  L            : 右へ移動

上下移動 (Vertical Movement):
  U            : 上へ移動
  O            : 下へ移動
  PageUp       : 上へ移動（代替キー）
  PageDown     : 下へ移動（代替キー）

====================================
  シミュレーション制御
====================================

Space          : 一時停止/再開
R              : リセット
Q または ESC   : 終了

====================================
  トラックパッド使用時のヒント
====================================

トラックパッドでマウスホイールが使えない場合：
- ズーム: Z/X キーまたは +/- キーを使用
- パン: 矢印キーまたは I/J/K/L キーを使用
- 回転: 左クリックしながらトラックパッドでドラッグ

推奨設定:
1. ズーム: Z/X キーが最も使いやすい
2. パン: I/J/K/L キー（ホームポジションから動かない）
3. 回転: 左クリック + トラックパッドドラッグ

====================================
  チュートリアル固有の操作
====================================

各チュートリアルには固有の操作がある場合があります。
詳細は各チュートリアルディレクトリの CONTROLS.txt を
参照してください。

例:
- 15_differential_drive/CONTROLS.txt - ロボット移動操作
- 18_camera_sensor/CONTROLS.txt - 解像度変更操作
- 22_dynamic_obstacle_avoidance/CONTROLS.txt - モード切替操作
