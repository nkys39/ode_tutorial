# 15: Differential Drive Robot

差動2輪ロボットの基本実装を学びます。実際のロボット（ルンバなど）と同様に、駆動輪2個とキャスター2個の構成です。

## 学習内容

- 差動2輪ロボットの運動学
- ヒンジジョイントによる駆動輪の実装
- ボールジョイントによるキャスターの実装
- モーター制御
- キーボード入力による制御
- 低摩擦キャスターによる安定性向上

## 実行

```bash
cd build
make 15_differential_drive
./15_differential_drive/15_differential_drive
```

## 操作

- **W**: 前進
- **S**: 後退
- **A**: 左旋回
- **D**: 右旋回
- **X**: 停止

## ロボット構成

### 駆動系
- **駆動輪 × 2**: 円柱形状、左右に配置
  - 高摩擦（mu = 10.0）で地面をしっかりグリップ
  - ヒンジジョイントで回転軸を固定
  - モーターで速度制御

### 支持系
- **キャスター × 2**: 球体形状、前後に配置
  - 低摩擦（mu = 0.1）で自由に回転
  - ボールジョイントで全方向に動ける
  - ロボットの安定性を確保

この構成により：
- **前後の安定性**: キャスターがロボットの傾きを防止
- **スムーズな旋回**: 低摩擦キャスターが回転を妨げない
- **ガタつき防止**: 4点支持で平面上を安定走行

## 差動2輪ロボットとは

左右の駆動輪の速度を独立に制御することで、移動と旋回を実現するロボットです。
掃除ロボット（ルンバ）、配送ロボット、車椅子などで広く使用されています。

### 運動学

```cpp
linear_vel = R * (v_left + v_right) / 2
angular_vel = R * (v_right - v_left) / L
```

- R: 車輪半径
- L: 車輪間距離（ホイールベース）
- v_left, v_right: 左右の車輪速度

### 逆運動学（制御に使用）

```cpp
v_left = (linear_vel - angular_vel * L / 2) / R
v_right = (linear_vel + angular_vel * L / 2) / R
```

目標の並進速度と回転速度から、必要な左右の車輪速度を計算します。

## 実装のポイント

1. **駆動輪**: 円柱（dCylinder）を90度回転して横向きに配置
2. **キャスター**: 球体（dSphere）で自由に転がる
3. **摩擦係数**: 駆動輪は高く、キャスターは低く設定
4. **初期速度**: 0に設定（勝手に動かない）
5. **安定性**: 前後のキャスターで4点支持
