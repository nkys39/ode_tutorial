# 01: Hello World (DrawStuff版)

## 説明

ODEとDrawStuffを使った最もシンプルなデモです。DrawStuffはODEに付属している3D可視化ライブラリです。

GLUTバージョンとの違い：
- より簡潔なAPI
- ODEに最初から付属
- テクスチャサポート
- カメラコントロールがデフォルトで組み込み

## 実行方法

```bash
./01_hello_world_drawstuff
```

## DrawStuffの操作

- **視点移動**: マウスドラッグ
- **ズーム**: マウスホイール
- **一時停止**: スペースキー
- **終了**: ESCキー

## 学べること

- DrawStuffの基本的な使い方
- ODEの初期化とワールド作成
- シンプルな描画
