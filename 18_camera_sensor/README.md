# 18: Camera Sensor

## 説明

深度カメラセンサーのシミュレーションです。カメラから見える映像が画面右上に表示されます。

## 実行方法

```bash
./18_camera_sensor
```

## 表示内容

- **3Dビュー**: シーン全体の俯瞰図
  - 青い球: カメラの位置
  - 黄色い線: カメラの視野（フラスタム）
  - 赤い箱と緑の球: 障害物
- **カメラビュー（右上）**: 深度カメラから見える映像
  - 明るい部分: 近い物体
  - 暗い部分: 遠い物体
  - 黒: 検出範囲外

## 学べること

- 深度カメラの実装
- RGB-Dセンサーの基礎
- レイキャストによる距離測定
- 深度画像の可視化
- カメラの視野（FOV）の表示
