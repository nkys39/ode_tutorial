# 18: RGB-D Camera Sensor

## 説明

高解像度RGBカメラと低解像度深度センサーを組み合わせたRGB-Dカメラのシミュレーションです。実際のRGB-Dカメラ（Intel RealSenseなど）のように、RGBと深度で異なる解像度を使用しています。

## 特徴

- **高解像度RGB画像**: OpenGLのオフスクリーンレンダリング（FBO）を使用して取得
  - デフォルト: 640×480（VGA）
  - キーボードで変更可能: 1280×720（HD）、1920×1080（Full HD）
- **低解像度深度センサー**: レイキャストによる物理的に正確な距離測定
  - 固定: 64×48
- **リアルタイム性能**: OpenGLレンダリングによるRGB取得のため、高解像度でも軽量

## 実行方法

```bash
./18_camera_sensor
```

## キーボード操作

- **1**: RGB解像度を640×480（VGA）に変更
- **2**: RGB解像度を1280×720（HD）に変更
- **3**: RGB解像度を1920×1080（Full HD）に変更
- **h**: ヘルプ表示
- **q**: 終了

## 表示内容

- **3Dビュー**: シーン全体の俯瞰図
  - 青い球: カメラの位置
  - 黄色い線: カメラの視野（フラスタム）
  - 赤い箱、緑の球、青い箱: 障害物
- **RGBカメラビュー（左上・大）**: 高解像度カラー映像
  - カメラから見える映像をそのまま表示
  - 解像度はキーボードで変更可能
  - OpenGLレンダリングによる高画質
- **深度センサービュー（右上・小）**: 低解像度深度情報
  - 64×48の固定解像度
  - 明るい部分: 近い物体
  - 暗い部分: 遠い物体
  - 黒: 検出範囲外

## 技術的詳細

### RGB画像取得方法

OpenGLのFramebuffer Object（FBO）を使用したオフスクリーンレンダリング：

1. カメラの視点で3Dシーンをテクスチャにレンダリング
2. `glReadPixels()`でピクセルデータを読み取り
3. RGBDImageのcolors配列にコピー

この方法により、640×480や1920×1080などの高解像度でも、レイキャストと比べて圧倒的に軽量です。

### 深度情報取得方法

レイキャストによる物理的に正確な距離測定：

1. 視野角を64×48のグリッドに分割
2. 各グリッドの方向にレイを飛ばす
3. 物体との交点までの距離を測定
4. RGBDImageのdepths配列に格納

### 計算コスト比較

- **レイキャスト（深度）**: 64×48 = 3,072回
- **OpenGLレンダリング（RGB）**: GPU処理により追加コストはほぼゼロ

もしRGBもレイキャストで取得すると：
- 640×480の場合: 307,200回のレイキャスト（約100倍のコスト）
- 1920×1080の場合: 2,073,600回のレイキャスト（約670倍のコスト）
