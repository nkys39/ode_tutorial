# 18: Camera Sensor

## 説明

RGB-Dカメラセンサーのシミュレーションです。カメラから見えるカラー映像と深度情報が画面上部に表示されます。

## 実行方法

```bash
./18_camera_sensor
```

## 表示内容

- **3Dビュー**: シーン全体の俯瞰図
  - 青い球: カメラの位置
  - 黄色い線: カメラの視野（フラスタム）
  - 赤い箱、緑の球、青い箱: 障害物
- **カメラビュー（左上・大）**: RGB-Dカメラのカラー映像
  - 障害物の色が見える
  - 空は青色で表示
- **深度ビュー（右上・小）**: 深度情報のグレースケール表示
  - 明るい部分: 近い物体
  - 暗い部分: 遠い物体
  - 黒: 検出範囲外

## 学べること

- RGB-Dカメラの実装
- カラー画像と深度情報の同時取得
- レイキャストによる距離測定
- 物体の色情報の取得（dGeomSetData/GetData）
- カメラの視野（FOV）の表示
- 複数のビューの可視化
